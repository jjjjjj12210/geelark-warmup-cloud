# GeeLark warmup — облачный запуск

Минимальный публичный набор скриптов для ежедневного прогрева парка
телефонов. Секретов и данных об аккаунтах здесь нет — репозиторий открытый
намеренно, чтобы облачная рутина claude.ai могла его клонировать (её
GitHub-коннектор видит только публичные репозитории).

## Секреты

Ни один скрипт не содержит ключей. Перед запуском в окружении должны быть
заданы переменные:

- `GEELARK_APP_ID`, `GEELARK_API_KEY` — GeeLark Open API
- `GONZO_API_KEY` — GonzoProxy

## Состояние — не в репозитории и не в Gist

`fleet.json` (привязка аккаунт↔телефон↔прокси) живёт файлом на Google Drive
(`geelark-fleet.json`), не в git. Так сложилось не случайно: облачная
песочница claude.ai пускает вызовы GitHub API только по путям вида
`repos/{owner}/{repo}/...` для уже подключённого репозитория — обычный Gist
(`api.github.com/gists/...`) под это не попадает и блокируется на уровне
инфраструктуры, какой токен ни давай. Google Drive этому ограничению не
подчиняется, и коннектор к нему уже подключён отдельно.

Пул/пуш делает не код, а сам агент рутины — вызовом Drive-инструментов
(`search_files`, `download_file_content`, `create_file`, `trash_file`),
потому что это MCP-инструменты, доступные модели, а не подпроцессу. Порядок
шагов и их точные параметры описаны прямо в промпте рутины, а не здесь.

## Запуск

    pip install -r requirements.txt
    python cloud_gate.py && python warmup_fleet.py --gap 2-8

(перед `warmup_fleet.py` рутина сама кладёт `fleet.json` в рабочую папку,
получив его из Drive — см. выше)
